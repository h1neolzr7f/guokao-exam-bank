# 国考行测总题库 · 按题型分类（2022–2026 汇总）

**独立于年份版**的横向题库：把 5 年 15 卷的全部行测题按「模块 → 考点」汇总，
**年份不参与分组与主排序**，只作为每题的属性列保留，便于按题型做跨年统计、考点词频与去重分析。

> 原按年份归档的版本在 `国考真题_2022-2026/`，未做任何改动。本目录自包含配图，可单独拷走。

## 规模

- 全量题次：**1974**（每道题在每个卷的出现都保留）
- 唯一题目：**1197**（按 `qid` 去重；663 个 qid 跨卷重复，答案/题干/选项零冲突）
- 配图：**1684** 张，已复制到本目录 `assets/`
- 覆盖年份：2022、2023、2024、2025、2026（仅作属性，不影响排序）

## 排序与复现

排序键固定为「模块 → 考点 → qid」，**不含年份**。因此新增考试年度后重跑，既有题目顺序不会变化。
重建：`python tools/rebuild_all.py`（已把本脚本纳入流水线）。

## 使用提醒

1. 去重表用 `qid` 唯一标识题目；`出现年份`/`出现卷别` 为斜杠分隔的列表，需要展开时按 `/` split。
2. 资料分析的共享材料在分册中会随题保留（相邻同材料折叠为「共享材料同上一题」），CSV 的 `所属材料` 列亦可用。
3. 「政治理论 + 常识判断」是源库对原卷常识部分的二次拆分口径，做年份间模块题量对比时请注意 2025 年大纲变化。
4. 答案与解析均为机构回忆版，非官方标准答案；`国考真题_2022-2026/疑似争议题.csv` 列有机构间分歧。
5. 2022 副省级回忆版缺 1 题（常识模块），已如实体现在全量题次中，未补齐。

申论仍按年份归档在 `国考真题_2022-2026/`（15 套题本 + 结构化语料），本总题库只收录行测。
